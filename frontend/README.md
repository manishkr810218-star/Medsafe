# Frontend (React + Vite)

Open a VS Code PowerShell terminal in `frontend`, run `npm.cmd ci` and `npm.cmd run dev`, then open the Vite URL (usually http://localhost:5173). The frontend can run a clearly labelled fictional offline sample workspace if the API is unavailable. With the backend running, dev requests to `/api` are proxied to `http://localhost:4000` (override with `VITE_API_URL`). See the top-level README and `docs/JUDGES_MASTER_GUIDE.md` for the full workflow.
